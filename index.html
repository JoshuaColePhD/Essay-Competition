Use the same exported files you already have. The page supports drag-and-drop and standard file selection for `.csv`, `.xlsx`, and `.xls`.

Option 2

Load a Google Sheet

Paste a shareable Google Sheets URL and the page will pull the data directly. If the sheet is private, Google may block the request, so a CSV export is the safest fallback.

Tip: share the sheet with “Anyone with the link” if you want the browser to load it directly.
